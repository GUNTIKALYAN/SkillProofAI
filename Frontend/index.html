    About SkillProof AI

    SkillProof compares a resume with a job description and, when you provide a username, public GitHub activity.

    A status of “Not found” means the reviewed sources did not show that skill. It is not a judgment that you lack the skill. Private repositories, workplace code, and experience that is not on the resume or GitHub are outside this review.

    Keyword coverage is an overlap estimate. It is not an employer's applicant-tracking score and it does not predict whether an application will pass screening.
